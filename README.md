# LeetCode Solutions

## Descrição
Este repositório reúne minhas soluções para problemas de algoritmos e estruturas de dados do LeetCode, acompanhadas de notas sobre o raciocínio por trás de cada solução. 

**Linguagem:** Python 3

## Como o repositório está organizado

Cada problema possui sua própria pasta, identificada pelo número e pelo nome do problema:

```
0001-two-sum/
├── solution.py   # Implementação da solução
└── notes.md      # Explicação do raciocínio e da abordagem utilizada
```
